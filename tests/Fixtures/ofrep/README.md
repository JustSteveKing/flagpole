# OFREP's OpenAPI document

`openapi.yaml` is OpenFeature's Remote Evaluation Protocol, version 0.4.0, from
[open-feature/protocol](https://github.com/open-feature/protocol) at commit
`98c4e0de5583c0d79dd938b82975c80125335e92` (`service/openapi.yaml`), unchanged. It is licensed
under the Apache License 2.0, in `LICENSE` beside it.

Flagpole's conformance tests check every OFREP response against it (RFC-0005). To move to a newer
version of OFREP, replace the file, update this note, and see what the tests say.
